HAPPY BIRTHDAY MISHTI — WEBSITE PRESENT

Open index.html in a browser to view the website.
Keep the assets folder beside index.html and style.css/script.js.
This is a friendly birthday gift for Mishti. The photo gallery uses the supplied photos, including the additional campus photo, plus the supplied video.

To publish free with GitHub Pages:
1. Create a new GitHub repository.
2. Upload index.html, style.css, script.js, and the complete assets folder.
3. In repository Settings > Pages, choose Deploy from a branch and select main / root.
4. Save and wait for GitHub Pages to publish the URL.

Note: Google Fonts requires internet access; the page otherwise uses fallback fonts. The supplied video is included locally in assets.
